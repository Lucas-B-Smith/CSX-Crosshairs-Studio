CXS Crosshair Studio 1.0.0

CXS Crosshair Studio is a complete crosshair customization and overlay application for macOS and Windows. It allows players to create, edit, organize, and display accurate custom crosshairs over games and other fullscreen applications.

The app includes 52 built-in crosshair presets and a powerful visual editor for creating original designs. Users can combine lines, circles, dots, rings, squares, polygons, and other shapes into layered crosshairs. Every layer can be selected, moved, resized, rotated, duplicated, reordered, aligned, centered, copied, pasted, or deleted.

Editor features include:

• Classic and advanced layered editing modes
• Lines, circles, dots, rings, squares, polygons, and additional shapes
• Adjustable size, length, width, height, thickness, gap, angle, rotation, opacity, color, outline, and position
• Independent shape and layer controls
• Multi-select, alignment, distribution, and grid snapping
• Editor zoom controls
• Undo and redo history
• Copy, paste, duplicate, select all, and delete commands
• Buttons and keyboard shortcuts for common actions
• Live crosshair preview
• Automatic screen-center alignment

The preset library includes:

• 52 built-in factory presets
• Preset search and style filtering
• Favorites
• Custom preset creation
• Rename, duplicate, edit, reset, and delete controls
• Import and export using CXS JSON files
• QR-code generation for transferring presets
• A private local style assistant that recommends presets based on descriptions such as color, game type, size, mood, and aiming style

The overlay system provides:

• Transparent and click-through crosshair rendering
• Live updates while editing
• Exact screen-center positioning
• Per-display alignment calibration
• Multi-monitor support
• One-pixel and ten-pixel positioning shortcuts
• Adjustable overlay opacity
• Performance, recording, and tournament modes
• Automatic overlay startup
• Support for normal desktop use and borderless fullscreen games
• Automatic hiding over the CXS editor so the crosshair does not cover the app itself
• No game injection, game-file modification, aim automation, or input control

CXS also includes four configurable profiles. Each profile can be assigned a preset and a global keyboard shortcut, allowing players to switch crosshairs without leaving their game.

The application is local-first. Presets, profiles, favorites, settings, editor data, and monitor calibration are stored on the user’s computer and remain available without an internet connection.

Available builds:

• macOS 1.0.0 universal DMG for Apple Silicon and Intel Macs
• Windows 1.0.0 portable EXE for 64-bit Windows 10 and Windows 11

CXS Crosshair Studio is designed for players who want a flexible, accurate, easy-to-use crosshair system without modifying or interfering with their games.
